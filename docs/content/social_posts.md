## LinkedIn

Every month, an AP team somewhere approves the same diesel surcharge, converts the same quintals to kilos,
and rejects the same "/R" duplicate invoice. The only thing that knows how is one senior person's memory.

At #HackWithHyderabad 3.0 we built Precedent: an accounts-payable exception agent that remembers.

→ A 3-way match flags what doesn't agree (price, quantity, GST type, bank details, duplicates)
→ Hindsight recalls how our team resolved the same vendor's same problem before
→ The agent recommends, cites the past decisions, and clears it only if memory backs it up
→ Every human decision and override is retained, so the next one is better

On 11 weeks of replayed AP history: week 1, 0% of recommendations matched the team. Last 4 weeks: 100%,
with 88% of exceptions cleared automatically and zero wrong auto-clears. Same data with memory off: nothing
cleared. And when a "our bank account has changed" letter arrived, it blocked payment and cited the last
three call-backs.

Built with @Hindsight by Vectorize, Groq and Band AI.
